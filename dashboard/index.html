Algorithm Implementation Details

BFS Traversal

Traditional breadth-first search using std::queue. Explores URLs level by level with O(V+E) complexity.

Data Structure: std::queue<URL>
Time Complexity: O(V + E)
Space Complexity: O(V)

Priority Queue Crawling

Best-First Search using heuristic URL scoring with std::priority_queue. Prioritizes high-value pages.

Data Structure: std::priority_queue<ScoredURL>
Time Complexity: O(E log V)
Space Complexity: O(V)

PageRank Power Iteration

Ranks domains by importance using power iteration with damping factor d=0.85. Runs on complete graph.

Algorithm: Power Iteration
Time Complexity: O(k · E) where k=30 iterations
Damping Factor: 0.85

Tarjan SCC Detection

Identifies strongly connected components using single-pass DFS with discovery time and low-link values.

Algorithm: Tarjan's DFS-based SCC
Time Complexity: O(V + E)
Space Complexity: O(V)

Topological Sort (Kahn's Algorithm)

Applies BFS-based topological ordering on condensed SCC DAG. Uses in-degree counting.

Algorithm: Kahn's BFS on SCC DAG
Time Complexity: O(V + E)
Precondition: Acyclic graph (post-SCC)
